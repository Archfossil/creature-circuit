# creature-circuit
A game about collecting wonderous creatures, developing their battle powers, becoming the regional champion and proving yourself as the best trainer of all time.


# Creature Circuit (Browser / App Edition)

**Creature Circuit** is a strategic monster-training game inspired by classic 90s tabletop mechanics, adapted into a digital browser/app experience. Players travel across a map inspired by American National Parks, capture and evolve creatures across 8 elemental types, challenge regional Arbiters, and compete in an endgame championship gauntlet.

---

## 🎮 Play it

Needs **Node.js 20 or newer** (the current LTS is best). Vitest 4 won't start on older versions.

```bash
npm install
npm run dev        # http://localhost:5173. Also served on your LAN, so you can open it on a phone
npm test           # engine unit tests (Vitest), and the baseline: seeded seasons must play out exactly as saved
npm run baseline   # after changing the game on purpose: save the new baseline (review tests/baseline before committing)
npm run build      # type-check, then a production build to dist/ (static files, host anywhere)
npm run preview    # serve the production build
npm run docs:creatures  # regenerate docs/08-creature-checklist.md from the game data
npm run docs:moves      # regenerate docs/09-move-checklist.md from the game data
npm run docs:instincts  # regenerate docs/14-instinct-checklist.md from the game data
```

The game runs in any modern desktop or mobile browser that supports WebGL. It saves to `localStorage` automatically. It can be installed as a PWA ("Add to Home Screen"), and the production build works offline.

### 🌐 Online play

Online multiplayer needs the small Node server in `server/`. It serves the built game and relays turns over WebSockets at `/ws`.

```bash
npm run build && npm start     # http://localhost:8787 (set PORT to change it)
# while developing: run `npm run server` alongside `npm run dev` (Vite forwards /ws to port 8787)
```

**Deploying on Render:** `render.yaml` is a Render Blueprint. In Render, choose **New → Blueprint** and pick this repository. It builds with `npm ci && npm run build`, starts with `npm start`, and health-checks `/health`. Rooms are kept in memory, so a restart (or a sleeping free instance) closes them. Every browser keeps its last copy of the match, and **🌐 Online → Reopen as host** puts it back in a new room.

## 🛠️ Tech Stack
- **Rendering:** [Three.js](https://threejs.org) (WebGL). The low-poly Margos map, the battle arenas and every creature model are generated procedurally from the data, so no 3D art assets are needed yet.
- **Language/Build:** TypeScript (strict) + Vite. The UI is plain DOM and CSS (no framework) to keep it light on phones.
- **UI style:** a tabletop look built from index cards: chunky outlines, ruled-paper creature cards and animated dice. It is mobile-first, with bottom sheets on phones, centered panels on desktop, safe-area insets and landscape layouts.
- **Audio:** sound effects synthesized with Web Audio (no audio files). The ☰ Menu and Settings have a mute button and a volume slider (`settings.volume`, 0–100, default 80; `sound.ts` → `applyVolume` changes the master gain at once, on a squared curve so the slider feels even).
- **Tests:** Vitest 4 unit tests for the rules engine (`tests/`). The time limit is raised to 30 s in `vite.config.ts`, because a few tests simulate thousands of battles.
- **Tooling notes:** Vite 6 and Vitest 4 (the first versions clear of the `npm audit` advisories). `vite-node` runs the docs scripts. `.npmrc` sets `legacy-peer-deps=true`: Vitest 4 lists many optional peer plugins (coverage, browser, UI) this project doesn't use, and resolving them crashes some npm versions. Run `npm audit` to check dependencies. It should report 0 vulnerabilities.

### Interpretations & additions (open to change)
The docs leave a few points open. The prototype makes these calls:
- **Hotseat multiplayer** (title screen → 👥 Hotseat): 2–6 trainers share one browser.
  - **Setup:** each trainer is created in turn. Main colours lock as they're chosen, so no two trainers share one.
  - **Turns** go in seat order. When one trainer ends their turn, a "pass the device" screen hands over to the next, whose pending event and follower prompt then open.
  - **Shared world:** everyone shares the map (other trainers' minis stand at their nodes), the weather for each turn (rolled once, on screen, when the first trainer starts that turn, and applied to everyone; nobody rolls when ending a turn), and the one-of-each Legendaries. A Legendary beaten or held by anyone is gone for all; released, it returns for all.
  - **On screen:** a turn-order strip on the HUD shows whose turn it is. Tap a trainer’s name there to glide the map to them and light up their mini with a beam and ring in their colour (`spotlightTrainer`; `render/world.ts` → `spotlight`). This works online too, including while watching.
  - **Ending:** trainers who finish (Season Over or Champion) drop out of the rotation. When everyone is done, final standings rank them by result and Merits.
  - **Saving:** the match is saved separately from a solo journey (`state.ts` → `Match`, `nextSeat`, `takenColors`; `world.ts` → `allTrainers`).
- **Online multiplayer** (title screen → 🌐 Online; `server/index.mjs`, `src/net/online.ts`): hotseat rules, played turn by turn over the internet.
  - **Rooms:** the host opens a room and shares its 5-letter code or invite link (`?room=CODE`). Everyone creates a trainer in the lobby, with colours locked as they're picked, and the host starts the game.
  - **Turns:** only the trainer whose turn it is plays. Their browser runs the game and sends the match to the server after every move.
  - **Coming back** (a phone switching tabs or apps): returning checks the connection with a ping, since a dead one can look open (`checkOnline`), and a dropped one is retried until it's back (`reconnect`, `Online.reopen`). A turn in progress carries on: the copy on the server says who sent it last (`Match.by`), so the player's own copy is kept unless someone else played on. Lost graphics are rebuilt in place, and a tab the browser reloads rejoins its room (`sessionRoom`).
  - **Watching:** everyone else follows live: the trainer's token and moves, their dice and messages, and their battles round by round. Their dice show small in the corner, under any window you have open, and the map stays where you put it after the start of their turn. A battle doesn't take over the screen: a "<trainer> is in a battle" chip opens it at any point, caught up to the present (`viewFight`; `watchFight` keeps the events so far), with 🐾 My team, 🎒 My bag and 🗺️ Back to map (or Esc) in view. A duel against you opens by itself. While watching a battle, 🔺 Types (or T) opens the type chart for the matchup on screen. A pending event shows as "<trainer> is resolving <event>"; tapping it shows the choices read-only (`watchEvent`), and the window closes once it's answered. While waiting, watchers can tend their own team: unlock chart nodes, train stats and edit playbooks (🐾 My team), look through their bag (🎒 My bag; items are used on their own turn), and mark their 📍 next stop on the map. Each change is sent as a small edit (`engine/edits.ts` → `applyEdit`). The browser running the turn checks it with the usual rules and applies it to the shared match. If nobody is running the turn, the server holds edits until someone is.
  - **Turn notifications** (`ui/attention.ts`): a soft ping whenever it's your turn or someone needs an answer (Settings → Turn ping). If the game isn't the window you're looking at (`looking`: hidden or unfocused), the tab's title and icon flash and, if allowed, a system notification appears (through the service worker, as phones require). The lobby and Settings show whether the browser allows notifications, with a button to turn them on (asked from the click itself) and a test. The flashing runs on a worker's clock, as browsers slow a hidden tab's timers, and every 25 seconds the connection is checked so a dead one doesn't miss a turn.
  - **Server push** (`server/push.mjs`): with notifications on, the server also pushes "it's your turn" (and offers waiting for an answer) through the browser's push service, so it arrives with the tab closed or asleep. The service worker stays quiet if the game is being looked at, never rings twice for the same thing, and opens the room when tapped. Subscriptions are kept with the room, in memory, and only for the known push services. Needs https. The signing key is made fresh each start (browsers re-subscribe); set `VAPID_PRIVATE` to keep one and `VAPID_SUBJECT` to a contact URL. On iPhones and iPads it works once the game is added to the home screen.
  - **Trades and duels:** the other trainer is asked in their own browser, for up to two minutes, while the one asking waits (and can call it off). A prompt that's no longer wanted is taken down (`ask-cancel`). In a duel they also pick their creature's action each round from there, and their next creature after a knockout (within a minute, or the next in line goes in). Their prompt waits for the last round to finish playing on their screen, and shows their creature's Health, Stamina and Fatigue; its 🔁 Swap list shows each Swap Move as the challenger's does (`swapRow`). With nobody Following, they're asked who leads first (`duelLeadPick`).
  - **Host controls:**
    - **Turn timer** (off, or 1–15 minutes): when it runs out, the turn ends automatically.
    - **⏭ Skip turn:** ends the current trainer's turn for them.
    - **🎮 Play for…:** takes over the current trainer's turn from the host's browser, for someone who has stepped away.
  - **Reconnecting:** a trainer who reloads or drops out rejoins with the same code and gets their seat back. If either side of a duel drops, the battle and any prompt still waiting are sent again (`sendAgain`, `Online.askAgain`).
- **Hotseat interactions** (👥 Trainers on the action bar; `engine/interactions.ts`):
  - **Gifts:** send coins and items to anyone, anywhere (a courier carries them). Key items can't be given.
  - **Trades:** coins and items trade at any distance (by courier). Creatures only change hands when both trainers are on the same spot; away from each other, the button reads "🤝 Trade items" and creatures can't be offered or asked for. The other trainer accepts or declines on a "pass the device" screen. Nobody can give away their only creature.
  - **Challenges:** duel a trainer on the same spot (1 Initiative, once per opponent per turn), with an optional wager the winner takes. Both trainers command their own creatures: each round the challenger picks, then the challenged trainer picks in secret (hotseat: the device is passed over and back; online: in their own browser, within a minute or their creature acts on instinct). A trainer with nobody Following chooses who leads (if both must choose, neither sees the other's pick). After a knockout, the challenged trainer also picks which creature goes in next. Both sides earn trainer-battle XP. A fully knocked-out team is helped home to rest, without losing coins.
  - **Notes:** each trainer finds notes about gifts, trades and duels in a "While you were away" note at the start of their turn.
- **How to Play** (title screen, or ☰ Menu; content in `ui/guide.ts`): a guide with category tabs (Basics, Creatures, Battles, Places, Multiplayer, You & saves). Each category has topic tabs and Previous/Next links. A new journey or hotseat game opens a short welcome tour instead: five cards on the goal, a turn, creatures, getting stronger, and where to find the full guide. It has Skip, Back and Next.
- **Save management** (title screen → 💾 Saves; `state.ts` → `saveCopy`, `restoreCopy`, `listCopies`):
  - **Autosaves:** the solo journey, the hotseat game and the online game (the last state this browser saw) each autosave to their own slot. Each one can be continued, exported (a .json download) or deleted separately.
  - **Saved copies:** 📌 Save a copy (on the Saves screen, or ☰ Menu while playing) keeps a named snapshot of any solo, hotseat or online game. Up to 30 are kept in this browser. Each can be loaded back into its slot (after a confirm, since it replaces the game in progress there), exported, renamed or deleted. Loading an online copy brings it back as your saved online game; reopen it as host from 🌐 Online.
  - **Import:** an imported .json file goes into the saved copies, sorted by kind (online files keep their seat owners).
  - **Failed autosaves** (`state.ts` → `onSaveStatus`, `retrySave`; `app.ts` → `saveStatus`, `saveFailedSheet`): a warning stays on screen while the browser won't store the game, with a way to export it as it stands, delete saved copies and try again.
  - **Safety:** starting a new solo or hotseat game warns before replacing the one in progress, and Abandon Journey only deletes the game you're playing.
- **Trainer styles** (chosen at the start; eight, each with a perk and a drawback):

  | Style | Perk | Drawback |
  | --- | --- | --- |
  | ⚖️ Wanderer | Every city's stable counts as home: the doubled home Chanko Nabe anywhere. After a team wipe, choose which city to return to, from any city whose stable you've rested at this game (`world.ts` → `wipeOptions`; in a hotseat duel, the last one rested at) | None |
  | 🌲 Ranger | Up to Tier times a turn, an explore that finds Nothing refunds 1 Initiative (once at Tier 1, twice at Tier 2 …) | City actions cost +1 Initiative |
  | 🏙️ Urbanite | City actions cost no Initiative | Re-exploring costs 2 Initiative |
  | 🤝 Beast Whisperer | +1 to every recruitment roll | Trainer battles pay half the coins (Arbiters pay in full) |
  | 💰 Merchant | Markets 25% off (stacks with Baby Eyes), and +25% on every coin earned: prizes, finds, sales, events (at least +1) | −1 to every recruitment roll |
  | 🎖️ Battle Master | +2 XP per creature in every battle, win or lose | Totem creatures lose Morale every 5 turns, not 10 |
  | 💞 Caretaker | Camping tends 2 creatures per Initiative; stables give +1 extra Morale | −1 XP per creature per battle (min 1) |
  | 🧭 Pathfinder | First move each turn is free (doesn't stack with Trailblazer) | Stables cost +1 Initiative |
- **Encounter scaling** follows Trainer Tier. Starters begin at Lv 1 with an untouched chart. Wild and roaming-trainer levels sit around 2 × Tier − 1 (1, 3, 5, 7, 9: under that Tier's Arbiter), and a node's level shifts them by −1 to +2, so Tier 1 wilds are mostly Lv 1–2. Tier 1 can't roll Apex wilds. Tiers 3–4 roll one extra rarity die and Tier 5 rolls two. Roaming trainers bring more Prime/Apex creatures and bigger teams at higher Tiers (`world.ts` → `baseWildLevel`, `tierRarityDice`).
- **Energy** is generated at 2× the base formula (stage-1 Commons make 6), and energy/Prisma nodes on the progression chart grant +2. This leaves room for real playbook trade-offs against move costs of 1–5 (`species.ts` → `ENERGY_SCALE`, `creature.ts` → `NODE_ENERGY`).
- **Camping** (on wild nodes) ends the turn and spends all remaining Initiative. Each point tends one creature of your choice: it recovers all Health and clears Fatigue. KO'd and fully rested creatures can't be picked. The picker highlights what each creature will get back. With 0 Initiative left, camping does nothing, so it's never free end-of-turn healing (`world.ts` → `campTargets`).
- **Attack grid** (`moves.ts`): every typed energy cost from 1 to 5 has an elemental attack. Single-type attacks run 1–5 of one type. Dual-type attacks cover any split totalling 5 or less (1 Fire + 1 Water, 2 Fire + 1 Water, …). An uneven split hits as the type it spends more of. Even splits (1+1, 2+2) get one attack per type, so 2 Fire + 2 Grass exists as both a Fire and a Grass attack. That's 376 slots, and every type leads exactly 47 attacks. Hand-made attacks fill 40 and generated placeholders (`atk-…` ids, `placeholder: true`) fill the rest (see docs/05).
- **Signature moves**: the ★ chart node names its move with a short summary (e.g. "Learn Riptide (d8 Water attack)"). The chart's back shows the full move card until it's learned. The playbook editor lists it at the end, greyed out with a 🔒 note to unlock it from the chart.
- **Playbook editor**: a side panel (`cards.ts` → `playbookSidebar`) shows the creature's portrait, level, Nature, HP, Stamina and all eight stats (hover or tap one for what it does), the energy and slots left, and the picks so far with each one's expected damage and a ✕ to remove it. The stats the picks rely on light up: Power for Physical moves, Focus for Elemental ones, Speed for moves with a ⚡ modifier, Stamina for moves with Effort. On desktop the panel sits beside the list and stays put while it scrolls; on phones it sits above the list in a compact form. On phones and touch-only devices (`(max-width: 759px), (hover: none)`), the first tap on a move opens its details under the card instead of adding it (`moveDetail`): damage with this creature's Power or Focus, accuracy, Effort against its Stamina, speed, status and energy, plus **➕ Add move?** / **➖ Remove move**. Moves that don't fit stay tappable and say why (no slot, or not enough energy). A double-tap adds or removes a move at once. The list has type filters (dual attacks appear under both types, plus Physical and Support), sorting (cost, damage, speed, type, name) and an "only moves that still fit" toggle. Your current picks stay pinned at the top. **Recommend moves?** offers four goals: optimize physical power, elemental power, a balanced spread, or against a chosen type. The goal that suits the creature's stats gets a ★: a Power or Focus lead of 2+ points one way, otherwise balanced. Each goal shows its best 4-move set, with expected damage per move, and **Confirm playbook?** applies it (`creature.ts` → `recommendPlaybook`, `suggestGoal`, `expectedDamage`).
- **Recommended playbooks** (`creature.ts` → `recommendPlaybook`, `moveWorth`): each move is judged with the creature's own stats and Instinct against typical foes of its level, by everything it carries: all its damage dice, Cascade, crit range, accuracy and Zeroing In, its status and Potency, riders, Speed and Effort. A set is judged on its best two moves against every type (with more Armor, then more Ward), one useful support move, a quick move, and Purge moves the rest can set up. Rivals and Champions use the balanced set; in simulated fights it beats the automatic one by about 5 points.
- **Type chart** (Menu → Type Chart, or 🔺 Types / T in battle): a stacked list with one coloured pill per type, what it's strong against on the left and what it's weak to on the right. Matchups mirror (a type resists exactly what it's strong against), so each side is a single row. In battle, your move types are highlighted gold and the foe's blue, and the live matchups are ringed (`cards.ts` → `typeChart`). Each type's pill carries a badge for the status its elemental attacks inflict (`STATUS_FOR`; hover for what it does). Below the chart is a status section (`typeChartStatuses`): from the menu it's the full Status Effects guide; in battle it lists the statuses your playbook's elemental moves can inflict and the ones the foe's types may inflict, with the rules, and all 8 folded away below.
- **Stamina & Fatigue display** (`cards.ts` → `fatigueBadge`, `fatigueHelp`): your battle nameplate shows a thin blue Stamina bar under the Health bar, with Fatigue as a number in a warning diamond beside both (grey at 0, red when fatigued). The foe's nameplate shows its Fatigue diamond beside its Health bar (its Stamina stays hidden). Hovering it, or tapping it on a phone, explains the d10 check, the chance of losing the turn and what clears it. Creature cards show the same diamond next to the STA meter. The bar, the 💨 count and the diamond update the moment a move's Effort is spent or Stamina refills (a `stamina` battle event carries the creature's new values).
- **Teamwork** (`engine/teamwork.ts`): each creature has a Teamwork score with every teammate (`CreatureInst.teamwork`, by uid). Pairs on the active team gain 0.2 a turn (`travelTogether`, at the end of the turn) and +1 the first time one swaps in for the other in a battle (once per pair per battle: `Battle.teamworkPairs`). A pair's Teamwork is capped at half the lower Loyalty of the two (`teamworkCap`, applied whenever it's read), so the trainer has to keep both creatures' trust. When a Loyalty falls (a Legendary's drain, a failed low-Morale check), `settleTeamwork` brings the pair down to the new cap at the end of the turn and the drop is announced at the start of the next (`GameState.teamworkFell`). Every 2 Teamwork gives +1 to the Swap Move. New whole points are announced at the start of the next turn (`GameState.teamworkNews`) and when the battle ends (`Battle.teamworkGains`). Old saves' `affinity` scores are migrated (`state.ts` → `migrate`).
- **Swap Moves** (`data/swapMoves.ts`, `engine/swaps.ts`): the trainer sets the move each creature uses when it swaps in for each teammate (`CreatureInst.swapMoves`, by partner uid), from the 🔁 Swap Moves section of its card or the Change link on the battle swap screen. The card lists only the active team (`app.ts` → `teammatesOf`), so a big collection doesn't bloat it; a creature resting in a totem shows a short note instead, and choices set for creatures in totems are kept. The picker (`ui/cards.ts` → `editSwapMove`) opens with the pair side by side (`swapPair`): the Alpha, highlighted in gold as the one swapping in, and the partner swapping out in silver, with each one's Health, Stamina and stats, so the numbers in each move can be read against them. In every Swap Move description (the picker, the card's slots and the battle swap screen) the Alpha's name and the word "Alpha" are highlighted in gold and the partner's name in silver (`alphaText`; names are only marked when the two differ). Each move's `text` is a function of the pair's names (`SwapNames`; `swapText` fills them in, or "the Alpha" / "the partner" when there's no partner in mind), so it reads "Cragtidekit swaps in with an attack of Sproutle's type (Grass), powered by Sproutle's Focus.". The grey line below it, from `describeSwap`, names whose stats each number comes from. There are 5 neutral moves, 2 per type and a Boosted one per type; a typed one needs the partner (not the Alpha) to have that type, and Teamwork 1 or 2, while a Boosted one (`boosted`) needs both creatures to share the type, and Teamwork 3 (`swapLock`). An unset slot (for any trainer, wild creatures too) uses a neutral move picked at random for that pair and direction, seeded by the two uids so it stays the same (`defaultSwapMove`); the card marks it "random until you set one". Each move is data (`before` effects, an optional `hit`, `after` effects): `battle.ts` → `doSwap` runs it and `describeSwap` writes its text, so the card always matches the rules. Trainers watching an online match can set them too (`edits.ts`, op `swapMove`).
- **Instincts** 🔆 (`data/instincts.ts`; `engine/battle.ts` → the "Instincts" section): every species has a battle passive, shared by its evolution family, alongside its Nature (stats) and Ability (overworld). Each is data: a `trigger` (a moment: `enter`, `heartLost`, `hitPhysical`, `ko`, `miss`, `roundEnd`; optionally once a battle or on a d6 chance; effects `mod`, `status`, `heal`, `refill`, `cure`, `sting`) and/or `passive` rules (steady accuracy, no Zeroing In against it, shrug off the first status, immunities, Hold Fast, wider crits, status on 1–2, more Zeroing In, a bigger Clash die, first-round Speed, weather and last-heart stat boosts). The engine runs them through `fireInstinct`, `afflict` (every status goes through it), `takeHit` / `afterHit` (every blow) and the passive checks in `eff`, `accuracyMods`, `accDie`, `critOn`, `zeroGain` and `clashDieOf`. Leads take the field as round 1 begins, so the chosen lead's Instinct fires. Once-a-battle uses are kept in `Battle.instinctUsed`. There are 48 (six per type), all first drafts for the design team; hand-made families got one from their first type's pool and placeholders are dealt them in turn (`roster.ts` → `familyInstinct`). The card shows it in place of the old favourite Swap Move panel (its exact rules on hover, `instinctRules`), and so do the follower sheet and the starter picker. [docs/14](./docs/14-instinct-checklist.md) lists them all, generated by `npm run docs:instincts`.
- **Overheal** (`engine/battle.ts` → `mend`, `overhealCap`, `Battle.overheal`): healing from a move, a Swap Move or an Instinct beyond a full heart becomes Overheal, bonus Health that soaks up damage first (`takeHit`), up to half a heart (3), for the rest of the battle (kept while benched). Arena heals don't overheal. The AI values the Overheal a healing move would give (`effectValue`), at a fraction of what real Health is worth. The battle nameplate shows it as a gold striped end on the Health bar and a "+N" by the number (`Snap.over`), and the log says when it's gained and when it soaks a hit. Hold Fast counts it.
- **Move readouts**: in battle, tapping a move first shows what it will do, step by step in resolution order:
  - turn order (your Speed with the move's modifier vs the foe's)
  - Fatigue and Shock checks
  - the Stamina cost
  - accuracy (die, the Evasion it must beat, any ⌖ Zeroing In bonus, hit chance, crit rule, and what a miss would add)
  - damage (e.g. `d6 + Power 3 − foe Armor 1`, the type multiplier and the resulting range)
  - the status chance and other effects

  You then confirm (Enter) or go back (Esc). As the round plays out, each roll is captioned: the accuracy roll against Evasion, and the damage die with its full sum. The **Fast battles** setting skips the readout and the damage dice and keeps the old quick pace (`battle.ts` → `movePreview`, `DamageCalc`).
- **Trainer look**: when starting a journey, and any time from Menu → Trainer Look, you choose a top (long shirt, tee, pouch jacket, long coat and vest, each with or without a backpack, plus overalls and poncho), one of ten hats or none, one of ten hair styles or bald, skin tone, hair colour and pants colour, with a live preview from the front and behind. Tops, hats and hair each take one of five detail patterns (or plain), drawn in a secondary colour by a small shader (`trainerModel.ts` → `PATTERN_GLSL`, `patternMat`). The secondary colours also cover trim, the backpack, hair ties and the Streak style. Looks saved before patterns keep their backpack (`topOf`). Your main colour always goes on the top, the hat and the token's base. The same mini is your token on the map and stands behind you in trainer battles (`render/trainerModel.ts` → `playerLook`; saved as `trainer.look`, and older saves get a look derived from the name).
- **Trainer battles pay more XP**: every creature that fights a trainer, Arbiter or Champion gets +3 XP on top of its participation XP, win or lose. It stacks with knockout XP (`creature.ts` → `TRAINER_BATTLE_XP_BONUS`).
- **City Market, Carving Shrine and Workbench** (`world.ts` → `payFacility`, `facilityPaid`, `refundFacility`): free to browse. The first purchase, carving or craft at each one costs the city action's Initiative (the button shows it, e.g. `💰 6 · 1⚡`); after that, that facility in that city is paid for the rest of the turn (`flags.paid`, cleared by `endTurn`). If the purchase fails, the Initiative is refunded. Town markets and Workbenches stay free.
- **Odd Jobs** (`world.ts` → `doWork`, `workBlock`, `WORK_DIE`; `app.ts` → `workTile`, `work`): in every city and town, spend all your remaining Initiative on work. Each point rolls a d4 of coins (1–4 per point, so up to 20 from a full turn), paid through `earnCoins` so a Merchant's +25% applies to the total. Like camping, it uses up the rest of the turn, but it doesn't end it: free actions still work afterwards. Counted in `stats.worked`.
- **Workbench crafting** (`content.ts` → `RECIPES`; `world.ts` → `craft`, `autoIngredients`, `fitsSlot`; `app.ts` → `workbench`): every city and town has a 🛠️ Workbench. Each recipe has one slot per type, and any offering material with allure for that type fills it (universal materials fit anything). Grass + Water → 2 Vigor Salves, Grass + Charm → Calm Tea, Grass + Rock → Trail Mix, Charm + Fire → Lure Incense, Fire + Steel → Hush Smoke, Astral + Electric → Star Charm, Water + Fire + Astral → Hot Spring Elixir. The sheet pre-picks the least precious materials you own (lowest total allure, then the biggest stack) and lets you change each slot. Crafts count toward `stats.crafted` (shown in the trainer ID). New recipes only need a `RECIPES` entry.
- **Rivals and Champions** (`regions/margos/npcs.ts`, `engine/npcs.ts`; [docs/15](./docs/15-rivals-and-champions.md)): 12 Rivals and 8 Champions with favourite types, an Ace and a team that grows with the season. Each trainer keeps a record with everyone they've met (Menu → 🥇 Rival Trainers), can arrange to meet them in a city or town to battle or trade (`engine/npcTrade.ts`: creatures face to face, coins and items by courier; they favour their types, and a traded creature joins their team), trades texts with them (💬 Messages; `engine/messenger.ts`, voices in `data/texts.ts`), takes up side challenges (races, first-to contests and sillier ones; `engine/dares.ts`), and earns a Revenge bonus for beating someone who beat them. Champions tour the towns; the Circuit Standings simulate everyone's Merits and decide the Finals' bracket, where a Rival who keeps beating you (or whom you've battled most) earns a place.
- **Stadium Mode** (title screen; `engine/stadium.ts`, `ui/stadium.ts`): teams of three creatures at Lv 12 with their whole chart, every Nature perk and full Loyalty, built fresh for each battle from a short recipe. Against the AI (Champions, Rivals, a challenger, or Arbiters with tier 5 arenas), two players on one device, or an online room of two. Stadium trainers are never saved (`GameState.stadium`); teams are kept under their own key and can be shared as codes.
- **Debug saves** (`npm run debug:saves` → `debug/*.json`): turn 99 in Circuit Stadium with all 8 Merits, a full Codex and a trained team, solo and for two hotseat players. Import them from 💾 Saves.
- **Sponsorship** (`npcs.ts` → `sponsor`, `SPONSOR_RAPPORT`; `world.ts` → `atHome`, `sponsorFree`): a Champion who's firm friends with a trainer sponsors them. Their home city counts as the trainer's too, or if they're at home there already (or a Wanderer), its Nabe costs no Initiative. One sponsor at a time.
- **Rousing Salts** 🧂 (`world.ts` → `revive`): revive a KO'd creature anywhere with half its hearts (rounded up) and +4 Fatigue (`SALTS_FATIGUE`; cleared by camping, a Calm Tea, an Elixir or a Root Salve). 💰 16 in every city, Ridgeway, Valor Ridge, Shifting Depths and Circuit Stadium, and an uncommon find (about 2% of finds; more on the Forest Floor and Rainbow Plains). A Rival or Champion who knocks out the whole team offers to revive one creature instead of the trip home (`npcs.ts` → `mercyOffer`).
- **Trainer Halls**: every city has one. For a city action's Initiative you can battle a local trainer once per city per turn. City trainers are 1 level above the wild band, lean toward the city's type, and bring 2 creatures (3 from Tier 3). Normal trainer stakes apply: coins if you win, a few coins lost if you lose (`world.ts` → `hallBattle`, `hallBlock`).
- **Research Facility** (Quillhaven, a new town between Ridgeway and Saltmarsh Landing): release a recruited creature for its level × 2 (Common), 3 (Prime), 4 (Apex) or 5 (Legendary) coins. You can't release your last creature, your only active one, or your starter (`world.ts` → `releaseToResearch`, `releaseBlock`, `researchPayout`).
- **Battle School** (Valor Ridge, a new town between Mistfall and Thunder Spike): pay coins and leave a creature to earn 1 XP per coin, at 2 XP a turn. You're notified when it finishes; pick it up any time, early pick-ups keeping the XP so far. On pick-up, a d6 rolls its mood: 1–2 −2 Morale and −1 Loyalty, 5–6 +2 Morale and +1 Loyalty (`world.ts` → `enrollTraining`, `trainingProgress`, `pickUpTraining`; saved as `training`). **Retraining** at the same school: pick any new Nature (💰 6), Ability (💰 8) and/or Instinct (💰 10) for a creature; it stays overnight and is ready the next morning (`nextMorning`: the next day turn), then loses 1 Loyalty per change when picked up, as the drills are harsh (`RETRAIN_COST`, `RETRAIN_LOYALTY`, `retrainBlock`, `enrollRetraining`, `applyRetrain`; the course is a `training` entry with `retrain` set and no XP). A creature's own Ability and Instinct are stored on it (`CreatureInst.ability` / `instinct`, read through `abilityOf` / `instinctIdOf`, falling back to the species'), and its card notes when one was retrained. Two start-of-turn events do the same for free with three random options, like the Creature Caretaker does for Natures: the 🧑‍🏫 **Trail Tutor** (day, Ability) and the 🥁 **Drum Circle** (night, Instinct).
- **Explore the Depths** (Shifting Depths, a dead-end town at the bottom of Houndmouth Canyon, down the Sinkhole Stair; `world.ts` → `exploreDepths`, `depthsSpecies`): for 1 Initiative plus one offering material, a wild creature that craves it comes up to battle. It has one of the material's types (stronger allure, likelier type), with rarity rolled as at the Sinkhole Stair, a rare area, and that node's level. It has already accepted the offering, so the material's bonus counts toward recruiting it, on top of up to two more offerings. The town market sells Canyon Ochre and Ember Charcoal.
- **Legendary spots** (`map.ts`, `kind: 'legendary'`): seven across the map. In the north: Sunspire Summit (Solstara: Tier 3 and a Summit Pick), Ironwake Shoals (Thalassor: Tier 4, by ferry with a Ferry Pass) and Cloud Island's Eye of the Sky (Nimbalune: after Salem). In the centre and south: Willowheart Isle (central lakes, off Willow Lake, Tier 2, Grass/Water), Dunecrown Mesa (desert past Dustmere, Tier 3, Electric/Rock), Boglight Hollow (swamps past Mangrove Port, Tier 3, Water/Charm) and Caldera Heart (southern tip of Kilauea island, Tier 4, Fire/Steel). Each is on a short branch path. The centre and south ones hold roster placeholder Legendaries until those slots are designed.
- **One of each Legendary per game**: a Legendary is at its node only while it hasn't been beaten and no trainer holds it. Releasing one at the Research Facility returns it to its node to be challenged again (`world.ts` → `legendaryHere`).
- **Surrender** (`battle.ts` → `surrender`; `world.ts` → `finishBattle`): give up any battle with a trainer. It costs the coins and Initiative a wipe would, and 3 Morale for the creature that's out, but nobody is knocked out or sent home. In duels (either trainer): just the wager and the Morale.
- **Morale & Loyalty** (`creature.ts` → `MORALE_HIGH`, `MORALE_LOW`, `addLoyalty`; `world.ts` → `moraleAndLoyalty`):
  - High Morale (7+) earns +1 Loyalty each turn.
  - Loyalty unlocks Nature perks at their thresholds, permanently. It's no longer spent.
  - Low Morale (≤3) gives a warning. After that, each turn ending without a Morale gain rolls a d10 against Loyalty: above it, the creature leaves; otherwise it loses 1 Loyalty.
  - A creature never leaves if it's your only one.
  - **Starter traits:** after picking a starter, the new game wizard asks for its Nature (with its attributes shown as you pick), Ability (any of the eight) and Instinct (its type's six). They're passed to `newGame` as `StarterTraits` and kept on the creature (`ability`, `instinct`) even when they're the species' usual, so they last through evolution.
  - **Special bond:** your starter (`CreatureInst.bond`, set in `newGame`; old saves bond the first creature caught's line) never leaves from low Morale and can't be released or given away, so nobody can soft-lock themselves by running out of creatures. It's also stronger than others of its kind, to ease the opening: +1 Vigor and no attribute under 1, before its Nature (`creature.ts` → `stats`, `BOND_VIGOR`, `BOND_MIN_STAT`). Worked out from `bond`, so it lasts through evolution and applies to old saves. Its card shows a 🤝 Bond tag.
  - Legendaries arrive with 10 Loyalty and lose 1 every turn whatever their Morale. At 0 they return to their grounds on the map (`LEGENDARY_START_LOYALTY`, `LEGENDARY_LOYALTY_DRAIN`), so releasing them at the Research Facility first, or letting them cycle back, is routine.
  - Tapping or hovering the Morale/Loyalty chips on a card explains all of this. The team strip flags unhappy creatures with ⚠️.
- **Follower prompt**: at the start of each turn (after the weather and any event), a sheet shows who is following you, with Ability, Instinct, Morale and Loyalty. It lists the other creatures you could switch to. It appears when there's a choice: more than one healthy creature, or nobody following. Turn it off in Settings → "Choose a follower each turn". The HUD's Following chip opens the same sheet any time.
- **Battle lead**: your Following creature always leads. If nobody healthy is Following and more than one creature can fight, you choose the lead before round 1 (`world.ts` → `needsLeadChoice`, `battle.ts` → `chooseLead`).
- **Keen Nose** (overworld ability): when an explore turns up an item, the follower sniffs out three different finds and you keep one (`world.ts` → `discoverItem`, `claimFind`).
- **Running** from wild battles: d6 + (your Speed − foe Speed) ≥ 4. Followers with Quick Step always escape, and an escape with Quick Step gives back 1 Initiative (up to 5; `QUICK_STEP_REFUND`, `finishBattle`). On the Forest Floor running needs 7+ instead of 4+.
- **Hush Smoke** (💨, `hush-smoke`; city markets, Dustmere, Ridgeway, explore finds and the Merchant Caravan, 5): Lure Incense in reverse. On your next explore the encounter faces turn into a quiet Nothing (3) and a find (4), and Sweet Scent's 5 is a find again. On the Forest Floor a 3 is Nothing without the fear of the dark and a 4 is an exotic find. It sets `flags.repel`, and lighting either Lure Incense or Hush Smoke puts the other out (`world.ts` → `exploreRoll`, `exploreFloor`, `useItem`).
- **Trainer encounters**: on road and meadow nodes, a 3–4 explore roll may be a wandering trainer instead of a wild creature (prize: d6 coins).
- **Statuses**, one per type: Burn, Soak, Shock, Snare, Stagger, Sunder, Beguile, Daze. They come from elemental attacks (a damage roll of 1, or 1 to 1 + Potency), from each type's status move (on a hit), and from some Instincts and Swap Moves. Purge attacks deal extra damage to a statused foe. A creature whose Instinct keeps statuses off shows a 🛡 on its battle nameplate (`battle.ts` → `statusGuard`), and the move readout marks a status that won't land as blocked (`statusBlock`). A creature holds one status at a time. It lasts 3 rounds, counted only while that creature is in battle, and ends on a KO or when the battle ends. The in-game Menu → Status Effects lists exactly what each does (`moves.ts` → `STATUS_INFO`, `STATUS_FOR`).
- **Encounter tables** (`world.ts` → `pickSpecies`, `areaPool`): a biome's wild types (`BIOME_TYPES`, shown when you tap a node) decide who turns up. About 90% of encounters are locals, whose every type is one of the area's. The rest are strays: dual types listing that biome with only their first type native, which is how pairings no biome shares (Fire/Water …) are met (`STRAY_CHANCE`; 25% where only one local is awake at that rarity). Weather doubles the weight of its types where they're native and never brings in others. Roaming trainers draw from the same tables; Trainer Halls add their city's type.
- **Creature Codex** (the docs' creature catalogue): a species is "seen" once it takes the field against you, whether wild, trainer, Arbiter or legendary. Bench creatures that never come out stay unseen. Effigies can only be carved for seen species. Each Codex page lists the wild nodes whose biome pool can produce the species or its earlier stages, and its best offering materials.
  - **Browsing:** the Codex (☰ Menu) shows seen and recruited counts with a progress bar. You can search by name (unseen names stay hidden) and filter by type (either half of a dual type), biome, rarity and status (seen, recruited, not seen yet). It sorts by Codex order, name, rarity or type. Filters are remembered while the game is open.
- **Offerings**: a material's bonus is its highest `allure` value among the creature's types. Berries give +1 (Moonberry +2) to anyone. Up to 2 offerings go with each totem.
- **Roster table** (`roster.ts`): one slot per type and dual-type combination (36). Each slot has Common, Prime and Apex three-stage families plus a Legendary. The eight starter lines, Solstara, Thalassor and Nimbalune fill their slots. The other 333 are generated **placeholders** (`ph-…` ids, `placeholder: true`), to be swapped for real designs one slot at a time (see docs/05). Five extra placeholder Common families (`EXTRA_FAMILIES`, 15 creatures) sit beside the table, so every area has at least two local Commons and Primes, and all its types, by day and by night. Placeholder Legendaries without a Legendary spot aren't on the map yet (four of them now are: see Legendary spots).
- **Health** is 5 × Vigor, one bar notched into hearts of 5 with a heart badge counting those left (`creature.ts` → `HEART`, `totalHealth`, `maxTotal`; `cards.ts` → `healthBar`). It's stored as the current heart (`health`, 0–5) and the full hearts behind it (`vitality`). Healing and the end of a battle refill the current heart; lost hearts need rest. v3 saves are converted on load (`state.ts` → `heartsFromV3`).
- **Battle plates** show the Health bar. A 🗿 badge marks wild species you've already recruited.

- **Map size** (`regions/margos/map.ts` → `MAP_SCALE`, currently 1.75): every route between towns, cities, the Stadium and Amber's arena has 3–5 wild nodes (126 nodes in all). New nodes are added with the `added(…)` helper at the end of a route or of the routes list, so no existing id shifts.

Each trainer's latest battle is kept in their save (`GameState.lastBattle`, up to 250 lines), so in hotseat and online everyone has their own. Duels write one for each trainer, told from their side (`view`). It's left out of saved copies to save storage. Battles watched online are kept for the session only (Menu → Last Watched Battle).
- **Clash coin flip** (`battle.ts` → `resolveRound`; `ui/dom.ts` → `coinFlip`): when a Clash's rolls tie, a coin decides who acts first. The engine decides it up front (the clash event's `first` and `coin`), so the coin is flipped on screen and the winner announced before either attack.
- **Next-stop marker** (`ui/app.ts` → `markerOwner`, `markNextStop`, `findNextStop`; `render/world.ts` → `setWaypoint`): tap any node but the one you're on and choose **📍 Mark as next stop**. A small flag in the trainer's colour, with a pulsing ring, is planted on that node as a reminder between turns. It's one per trainer, saved as `GameState.waypoint`, and arriving there clears it (`state.ts` → `moveTrainer`, so rides and wipes count too). Only its owner sees it: in solo and hotseat it shows during that trainer's own turn; online each browser shows only its own trainer's marker, even while watching (never another trainer's while playing their turn for them). Online it can be set while watching; it's sent as a `waypoint` edit (`engine/edits.ts` → `setWaypoint`). Other browsers receive it with the match data but never draw it. While a marker is set, the location card shows a **📍 Your next stop** chip; tapping it glides the map to the flag and spotlights it in the trainer's colour, like the turn-order chips do for trainers (`render/world.ts` → `waypointPos`).
- **Clouds** (`render/world.ts` → `buildClouds`, `CLOUD_LOOKS`, `updateClouds`): fluffy low-poly clouds, each a dome of 8–12 rounded puffs plus a small crown, slightly see-through so the map shows beneath; only each cloud's core casts a shadow. They follow the weather, blending over a few seconds when it changes: white and fluffy on clear days, thin and hazy in the heat, wispy streaks racing by in Gusty Winds, dark and heavy in Rain, darker, taller and faster in a Thunderstorm, pale in Fog and Snowfall. Each look (colour, opacity, stretch, squash, drift speed) is one entry in `CLOUD_LOOKS`, keyed by the weather's `fx`.
- **Keyboard panning and zoom** (`render/world.ts` → `PAN_KEYS`, `ZOOM_KEYS`, `keyPan`): on desktop, holding W-A-S-D or the arrow keys pans the map (diagonals work, and it moves faster when zoomed out), and holding Q zooms out and E zooms in (smoothly, within the scroll wheel's limits), alongside dragging and the scroll wheel. It's ignored while typing in a field, with a sheet open, during a battle (where S still means swap), on the title screen, and with Ctrl, Alt or ⌘ held, so browser shortcuts keep working.
- **Double-tap shortcuts** (Settings → Double-tap shortcuts; `ui/app.ts` → `onNodeDoubleTap`): double-tap an adjacent node to travel there, or the city or town you're in to open its menu. Arenas aren't included, since their buttons start battles.
- **Getting around** (`world.ts` → travel items & rides; `ui/app.ts` → `bikeFlow`, `taxiFlow`, `travelItemFlow`, `glide`): the map is big, so a few things cover ground faster. Rides never explore on the way or where you land, and only work on the mainland (`travelBlock`). The full table is in [docs/10-events.md](./docs/10-events.md#getting-around).
  - 🚲 **Bike** (Lumber Hollow, 25 coins, kept and owned once, `Item.unique`): once a turn roll a d6 and ride up to that many steps for free (`rollBike`, `bikeReach`, `rideBike`). Rides stay on land (no `sea`, `portal` or `rope` routes), keep every gate (`routeBlock`, shared with `canMoveTo`) and never stop at a Legendary's grounds. A roll not yet ridden waits on the 🚲 button until the turn ends (`flags.bikeRoll`).
  - 🚕 **Taxi Ticket** (city markets, 10): from a city to any other city; remaining Initiative drops to 0 (`rideTaxi`).
  - 🕊️ **Homing Feather** (Dustmere, Quillhaven, 8): from anywhere on the mainland to the home city, or for a Wanderer any rested city; Initiative drops to 0 (`useFeather`).
  - 🥜 **Trail Mix** (city markets, Mistfall, Ridgeway, explore finds, 6): +1 Initiative up to 5, once a turn (`eatTrailMix`).
  - Events: 🎈 **Hot Air Balloon** (day, a free ride to one of three cities) and 🚌 **Night Coach** (night, 4 coins to one named city).
- **Dice on screen** (`ui/dom.ts` → `rollDice`, `readHold`): the dice tumble first, and the result (the caption and each die's label, e.g. "3–4 Encounter") appears only once they land. Rolls on the map pass `{ read: true }`: the result stays up long enough to read (about 1.1 s plus a little per character, capped near 3.4 s), and the next roll waits until the overlay has faded. Follow-up rolls come one at a time: an item find rolls Explore ("You discovered something!"), then a separate Find d6 that names the item. A creature's Rarity Stars dice still roll together, since they add up. Fast dice shortens the spin but keeps map results readable.
- **Battle XP**: every creature that took part earns participation XP when the battle ends, **win or lose** (KO'd ones too): `3 + (toughest foe level − its level)`, clamped to 1–5. The creature that knocks out an opponent also gets a KO bonus right away: `5 + 2 × (foe level − its level)`, clamped to 2–10. Running away earns nothing (`creature.ts` → `participationXp`, `xpForWin`; `battle.ts` → `awardBattleXp`).
- **Town stables** fully recover the team (KOs, Health, Fatigue) and give +1 Morale for the same Initiative as a city action, but serve no Chanko Nabe buff. That stays a city specialty (`world.ts` → `rest`).
- **Progression charts are skill trees.** Each node lists the nodes linked above it (`requires`), and all of them must be bought first. Evolving takes the center path: best stat → +2 energy **and** a third stat → second stat → +1 Vigor → Evolve (6 points). Later stages (and species that never evolve) have Vigor early, in the third stat's place, and a second one further down unless the species is naturally high in Vigor (`Species.sturdy`); Sproutle's first chart has none (`Species.bulky`). The side branches (Signature → +2 secondary energy, Speed → Stamina) are optional, and any you skip are left behind when the creature evolves. At the final stage, the Capstone needs both the center path and the Stamina branch (8 points), and a +2 Prisma node hangs off the secondary-energy branch. Once a final-stage chart is complete, each further level-up point trains +1 to a stat of the player’s choice (`trainStat`), so a level-up badge can always be cleared.
- **Saves** carry a `version` (currently 4). Older saves are migrated on load (`state.ts` → `migrate`): v1 → v2 doubles energy earned from chart nodes; v2 → v3 renames bought chart nodes to their skill-tree ids and keeps every earned bonus; v3 → v4 converts Health to 5 × Vigor. Every load also updates playbooks: a placeholder attack that a hand-made move has since replaced becomes that move (`moves.ts` → `RETIRED_MOVES`, `currentMoveId`), and ids that no longer exist are dropped. Matches sent by an online room go through the same migration (`migrateMatch`, in `applyState`), since the room may have been started by an older build.
- **Cloud Island** (`map.ts` → `CLOUD_RING`, `CLOUD_EYE`; `world.ts` → `portalOpen`, `stepCloudLap`): a portal in Aurora Peak opens at night (and all Winter) to a ring of six cloud wilds off the north-west coast. A full lap (6 steps the same way round, over any number of turns, without leaving) earns a match with Salem. Every step onto the island costs +1 Initiative per Tier (capped at 5), and items found there wait in a Cloud satchel until the trainer escapes through the portal; a team wipe loses them. The island is cotton-candy pink and purple with dark purple spires, and midnight-plum paths and node tiles so the route stands out. The rules (with the trainer's live status) show in a prompt before stepping through the portal, and on the island a ☁️ HUD chip shows the lap, the satchel and the portal, and opens the rules (`cloudRules`, `cloudPrompt` in `app.ts`). The island has universal offerings (Cloud Silk +1, Stardust +2, Moonbow Prism +3 for any creature) and its own events. After Salem, bridges open to the Eye of the Sky, where the Legendary Nimbalune (Water/Astral) waits. In Winter, Aurora Peak is always under Aurora Night.
- **The Forest Floor** (`map.ts` → `FOREST_FLOOR`; `world.ts` → `exploreFloor`, `trailProgress`): Dahlia's arena hides on a single dark node below Gloomshade, reached by rope with a Canopy Rope. Exploring it rolls a d8: 1–2 nothing (−1 Morale for the active team), 3–4 a wild night creature (running needs 7+ unless Quick Step), 5–6 an exotic find (Duskberry, Root Salve, Heartwood Resin, Glowcap), 7–8 a sign of Dahlia's Trail. 3 + Tier signs reveal her arena. Leaving by choice or defeat loses the trail. Once she's beaten, the die drops to a d6 (the same table without the trail). Only its five hostile, forced events happen there. There's a rules prompt before climbing down, and a HUD chip while there.
- **Iron Coast Gauntlet** (`regions/margos/gimmicks/gauntlet.ts`): before Stella will battle, a trainer must beat 2 local trainers per Tier (2, 4, 6, 8, 10). They're Steel-leaning, one level above Trainer Hall opponents, and the last one is a level higher still. Matches can be spread over turns, with Stable rests in between, as long as the trainer stays in Iron Coast. Leaving (travel, or being sent home) resets the count; a lost match doesn't. Once cleared, Stella can be challenged at any time.
- **Lantern Glade & the Rainbow Plains** (`map.ts` → `LANTERN_GLADE`, `RAINBOW_PLAINS`, `WISP_REGION`, `WISP_SPOTS`; `world.ts` → `prismType`, `exoticFind`; `state.ts` → `rollWisp`, `wispLit`): the Mistfall–Hollow Crest road is an ordinary route. Off its Fogbank Path, a branch runs north-west (south of Aurora Peak) to the town of Lantern Glade, and behind it the four nodes of the Rainbow Plains. Entering needs a Fog Lantern holding a **wisp**. A wisp waits at a random mainland wild node, town or city (`flags.wispAt`); **Check** the lantern in the Bag to reveal it (a 💫 marker on the map), then walk there to catch it. Leaving the Glade and Plains lets the wisp go and a new one appears elsewhere; a brand-new lantern needs a wisp first. On the Plains, every new day (odd turns) rolls one creature type (`prismSeed`, never the same two days running); wild creatures are all that type, rarity is bumped one step (Common→Prime→Apex, past the Tier cap), finds are exotic (Heartwood Resin, Glowcap, Cloud Silk, Stardust, Moonbow Prism), and the ground recolours to the type's colour (`render/world.ts` → `setPrism`).
- **Active effects** (`world.ts` → `activeEffects`; `app.ts` → `effectsSheet`): while anything lingers (a Chanko Nabe buff until the next battle, lucky stars from a Star Charm or the Fortune Teller, Hush Smoke, Lure Incense, a wisp in the lantern), a yellow HUD pill shows its icons and opens a sheet that explains each. The Nabe also shows as a toast, a log line and a header chip in the battle that uses it. New lingering effects only need an entry in `activeEffects`.
- **Arbiter gates** follow the city lore: Salem needs a full lap of Cloud Island, Fabian must be found in disguise, Dahlia must be found on the Forest Floor by following her trail (the climb down needs a Canopy Rope, sold in a random town each game), Stella needs the Iron Coast Gauntlet cleared, and Katy needs a Root Whistle (also in a random town each game, different from the rope's). Notice Boards and the arena hints name this season's towns (`state.ts` → `rollKeyTowns`, `keyTownOf`; `map.ts` → `KEY_ITEM_TOWNS`).
